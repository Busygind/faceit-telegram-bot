# Проверка Telegram бота на Mac

Бота `@road_to_3_elo_bot` можно проверить в настоящем Telegram, пока доступ к Telegram Serverless находится в листе ожидания. Код запускается на твоём Mac и получает команды через long polling. VPS, публичный адрес, HTTPS сервер и доступ к Serverless для этого не нужны.

Это временный запуск, а не размещение на серверах Codex. Бот работает, пока процесс запущен, Mac не спит и подключён к интернету. Закрытие терминала, выключение Mac или потеря сети прервут доступность. После остановки процесса Telegram профиль бота останется, но новые команды обрабатываться не будут.

- Ожидаемое имя бота: `road_to_3_elo_bot`.
- Единственная разрешённая по умолчанию группа: `-1004393474895`.
- Ник FACEIT для проверки: `aghori-`.
- Файл Bot API token: `/Users/busygind02/IdeaProject/faceit-telegram-bot/.secrets/telegram-bot.token`.
- Файл FACEIT API key: `/Users/busygind02/IdeaProject/faceit-telegram-bot/.secrets/faceit.key`.

Оба ключа уже сохранены локально. Не вставляй их в команды, переписку, скриншоты, issue или файлы исходников. Не показывай содержимое `.secrets`, не запускай `cat` для файлов с ключами. Runner читает ключи непосредственно из защищённых файлов; их значения не нужны в терминале.

## Подготовить группу

1. Добавь `@road_to_3_elo_bot` в тестовый чат.
2. Назначь его администратором. Это нужно для надёжной проверки членства пользователей, а не только для отправки сообщений.
3. Разреши боту отправлять сообщения, фотографии и опросы.
4. Разреши удаление сообщений, если хочешь, чтобы бот удалял исходную команду `/setts` после сохранения пароля.
5. Не запускай одновременно другую копию этого же бота: один Bot API token должен иметь только один polling процесс.

Не требуется делать группу публичной или выключать privacy mode. Команды с упоминанием бота работают и в группе с несколькими ботами, например `/menu@road_to_3_elo_bot`.

## Открыть терминал и проверить доступность Node

Открой новое окно Terminal и выполни:

```bash
cd /Users/busygind02/IdeaProject/faceit-telegram-bot
node --version
npm --version
```

Нужна установленная Node.js 24 или новее. Если терминал пишет `command not found`, открой новое окно после установки Node. При необходимости для текущего окна добавь установленную локальную Node в PATH:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Для локального runner не нужно выполнять `npm ci`, устанавливать Telegram Serverless CLI или получать Serverless CLI access token. Используются встроенные возможности Node и уже подготовленные модули проекта.

## Проверить доступ без запуска бота

Из каталога проекта выполни:

```bash
cd /Users/busygind02/IdeaProject/faceit-telegram-bot
npm run local:check
```

Проверка читает защищённые файлы ключей и выполняет только проверочные запросы к Telegram: определяет бота, наличие webhook, доступ к группе и роль бота в ней. Она не отправляет сообщения, не получает и не подтверждает updates, не создаёт локальную базу и не меняет настройки Telegram. FACEIT ключ здесь проверяется на наличие и формат; фактический запрос FACEIT выполняется при командах `/last` и `/stats`.

Успешный результат содержит событие `LOCAL_PREFLIGHT_OK`, имя `road_to_3_elo_bot`, разрешённый ID чата и поле `canDeleteMessages`. Ключи и текст сообщений в вывод не включаются.

Если `canDeleteMessages` равно `false`, основные команды могут работать, но бот не сможет удалить команду с реквизитами TeamSpeak. Выдай право удаления или удаляй такую команду вручную.

Если появился `WEBHOOK_ACTIVE`, остановись: у бота уже настроен другой получатель команд. Локальный runner специально не удаляет webhook и не сбрасывает очередь updates. Сообщи мне этот код ошибки — выберем безопасное переключение.

## Запустить бота

```bash
cd /Users/busygind02/IdeaProject/faceit-telegram-bot
npm run local
```

Дождись событий `LOCAL_PREFLIGHT_OK` и `POLLING_READY`. Терминал остаётся занят, пока бот работает; это нормально. Не запускай вторую копию в другом окне и не запускай параллельно Serverless версию с тем же token.

При первом запуске создаются:

- `/Users/busygind02/IdeaProject/faceit-telegram-bot/.local-data/bot.sqlite` — настройки чатов в зашифрованном виде, технические задания и отметки отправки, следующий offset Telegram.
- Временные файлы SQLite `bot.sqlite-wal` и `bot.sqlite-shm` рядом с базой.
- `/Users/busygind02/IdeaProject/faceit-telegram-bot/.local-data/polling.lock` — защита от одновременного запуска двух процессов.
- `/Users/busygind02/IdeaProject/faceit-telegram-bot/.secrets/local-encryption.json` — отдельный ключ шифрования реквизитов TeamSpeak.

Это рабочие данные, не мусор после тестов. Не удаляй базу или ключ между перезапусками. Сохраняй защищённую резервную копию ключа отдельно от базы: без него нельзя расшифровать сохранённый TeamSpeak. Если база уже существует, а ключ потерян, runner откажется создавать новый вместо старого.

## Пройти сценарий проверки в группе

Все следующие команды отправляются **в Telegram группе**, не в Terminal и не в личке боту. Для надёжности можно добавлять `@road_to_3_elo_bot` сразу после имени команды.

### Меню и доступ

```text
/menu@road_to_3_elo_bot
/setup@road_to_3_elo_bot
```

Проверь, что появились кнопки меню, а `/setup` показывает ID `-1004393474895`. Кнопки «Последний матч» и «30 матчей» подсказывают синтаксис: ник передаётся заново в каждой команде, список игроков не хранится.

### Последний матч

```text
/last@road_to_3_elo_bot aghori-
```

Ожидается PNG-карточка FACEIT Dark с обзором последнего завершённого матча CS2: результат, доступная статистика игрока и ссылка на матч FACEIT. Если FACEIT ещё не опубликовал подробную статистику последнего матча, бот сообщает об этом, а не подменяет матч более старым.

### Последние 30 матчей

```text
/stats@road_to_3_elo_bot aghori-
```

Ожидаются карточка FACEIT Dark и текст со статистикой доступных завершённых матчей. При неполной статистике у метрик указано покрытие; отсутствующие данные не превращаются в нули.

В обычном локальном запуске бот сам последовательно догружает последние 30 матчей: одно уведомление о загрузке, затем карточка без дополнительного текста. Нажимать «Продолжить» после каждой порции не нужно. Checkpoint сохраняется после каждых 4 GET.

Кнопка «Продолжить» остаётся только как запасной путь: если FACEIT запросил паузу, история слишком большая для одного автоматического прохода либо достигнут мягкий лимит времени. Автопроход ограничен 32 порциями и проверяет 90 секунд между порциями; начатый batch из 4 запросов может закончиться позднее. Нажатие продолжает тот же запрос без повторного ника. Если FACEIT просит подождать, выдержи указанный интервал. Не отправляй много одинаковых команд подряд.

### Опрос

```text
/poll@road_to_3_elo_bot
```

Проверь вопрос `Играть сегодня (время по МСК)` и варианты в таком порядке:

- `да, в 17`
- `да, в 18`
- `да, в 19`
- `да, в 20`
- `да, в 21`
- `да, в 22`
- `да, в 23`
- `да, позже`
- `нет`

Опрос должен позволять выбрать несколько ответов и изменить голос. Голоса открытые, это не викторина; автоматического закрытия, закрепления и перемешивания вариантов нет. Вариант «нет» технически можно выбрать вместе со временем — ограничение исключительности не добавлено. Повторная новая команда создаст новый опрос, поэтому для первичной проверки достаточно одной.

Обе FACEIT-команды возвращают отрисованные PNG-карточки в едином стиле FACEIT Dark: графитовый фон, оранжевый акцент, крупные числа. `/last` показывает счёт и результат, карты, K/D/A и составы; `/stats` — сводку выборки, показатели с покрытием и карты. Команды возвращают только изображения без текстовых отчётов и подписей; ссылка на матч находится на кнопке. При недоступной статистике или отсутствии матчей карточка честно показывает отсутствие данных. При неизвестном результате отправки файл вслепую не повторяется. Постоянный кеш готовых отчётов и Telegram `file_id` описан в [README](../README.md#кеш-last-и-stats).

### TeamSpeak

Команду настройки может отправить только администратор группы от собственного аккаунта. Весь текст после адреса — пароль, включая внутренние пробелы.

**Внимание:** команда отправляется прямо в группу, поэтому реквизиты первоначально видны её участникам. Автоматическое удаление после сохранения не отменяет возможные уведомления и просмотр сообщения. Для первого теста используй вымышленные реквизиты:

```text
/setts@road_to_3_elo_bot 203.0.113.10:9987 тестовый пароль
/ts@road_to_3_elo_bot
```

Ожидается подтверждение настройки без повторения пароля; затем `/ts` показывает реквизиты только текущего чата. При наличии права удаления исходная команда `/setts` удаляется. Если удаление не удалось, бот сообщает об этом — удали команду вручную.

Чтобы сохранить сервер без пароля, нужно явное указание:

```text
/setts@road_to_3_elo_bot --no-password 203.0.113.10:9987
```

Обычная команда без пароля не должна стирать ранее сохранённые данные. Реальные адрес и пароль вводи только после проверки сценария. Бот не подключается к TeamSpeak и не устанавливает клиент — он хранит и выдаёт реквизиты.

## Остановить и повторно запустить

1. Вернись в окно Terminal, где работает бот.
2. Нажми `Ctrl+C` один раз.
3. Дождись завершения процесса и возвращения приглашения командной строки.

Остановка отменяет сетевые запросы и дожидается завершения текущего обработчика, после чего закрывает SQLite и освобождает lock. Не удаляй рабочие файлы вместо корректной остановки.

Для повторного запуска выполни ту же команду `npm run local`. Сохранённый offset и технические отметки отправки используются повторно; заново вводить TeamSpeak не нужно. Неподтверждённые updates могут прийти повторно, а идентификаторы обработанных запросов защищают от повторной отправки там, где результат уже зафиксирован. Это не обещание строгой exactly-once доставки при любом сетевом сбое: сообщение с потерянным ответом Telegram автоматически заново не отправляется.

## Если появилась ошибка

| Код или симптом | Что проверить |
|---|---|
| `LOCAL_TOKEN_FILE` или `LOCAL_FACEIT_FILE` | Нужный файл существует, это обычный файл, а не symlink; доступ к нему только у владельца. Не отправляй содержимое файла. |
| `LOCAL_TOKEN_FORMAT` или `LOCAL_FACEIT_FORMAT` | Файл содержит один соответствующий ключ без пояснений. Bot API token и Serverless CLI token — разные ключи. |
| `LOCAL_BOT_MISMATCH` | Сохранён Bot API token другого бота; ожидается `road_to_3_elo_bot`. |
| `TELEGRAM_AUTH` | Telegram не принял token. При его перевыпуске обнови локальный файл безопасно. |
| `LOCAL_GROUP_UNAVAILABLE` | Бот добавлен в нужный чат; ID группы указан правильно. |
| `LOCAL_BOT_NOT_ADMIN` | Выдай боту права администратора в группе. |
| `WEBHOOK_ACTIVE` | Не удаляй webhook наугад. Нужен согласованный переход с другого запуска. |
| `LOCAL_ALREADY_RUNNING` | Копия runner уже работает. Найди её окно и останови через `Ctrl+C`. |
| `LOCAL_STALE_LOCK` | После аварийной остановки остался lock. Не удаляй его вслепую: сначала нужно убедиться, что прежний процесс действительно не работает. Сообщи мне код — проверим и освободим безопасно. |
| `POLLING_CONFLICT` | Этот же token получает updates в другом процессе или окружении. Останови конкурирующий запуск, а не создавай ещё один. |
| `LOCAL_KEY_MISSING` или `LOCAL_KEY_INVALID` | Восстанови исходный локальный ключ шифрования. Не генерируй замену поверх существующей базы. |
| `LOCAL_DIRECTORY_UNSAFE` | Рабочая папка доступна не только владельцу или является symlink. Не ослабляй проверки; нужно исправить права. |
| `POLLING_RETRY` | Временная ошибка сети или ограничение Telegram; runner ждёт и повторяет запрос чтения. |
| `POLLING_HANDLER_FAILED` | Обработка одного update несколько раз не завершилась. Offset не продвинут; сообщи код ошибки перед повторным запуском. |
| Бот молчит, но ошибок нет | Mac не спит, есть интернет, процесс работает; команда отправлена в разрешённую группу от аккаунта участника. Попробуй `/menu@road_to_3_elo_bot`. |

Можно сообщать безопасный код ошибки и название команды. Не присылай исходные токены, пароли, содержимое `.secrets`, SQLite или необработанный Telegram update.

## Когда появится доступ к Serverless

Локальный runner и Serverless используют общий код команд, но разные базы и ключи шифрования. Локальные настройки TeamSpeak, задания и offset автоматически в Telegram Serverless не переносятся.

Перед включением Serverless остановим локальный процесс, настроим облачное окружение и отдельно проверим доставку команд. Не запускай обе версии одновременно. При необходимости переноса реквизитов запланируем его отдельно; файлы с секретами в чат не отправляются.

### Чистый вид карточек

Для `/last` ожидается широкое изображение 1200×1360: своя команда и соперники отдельно, обе таблицы с ADR и сортировкой по нему по убыванию. В `/stats` карты идут по убыванию винрейта, подписи показателей сокращены. Служебных повторов покрытия, названия шаблона или API на картинках нет. Пустые значения остаются «—», неполные данные и время обновления не скрываются.
