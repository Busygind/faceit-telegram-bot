# Личный FACEIT в чате

Каждый действующий участник группы или супергруппы, куда добавлен бот, настраивает только себя. Списка разрешённых чатов нет. Администраторские права пользователя для личной привязки не нужны; самому боту нужны права для надёжной проверки членства. В личных диалогах и каналах эта настройка не выполняется.

## Первый запуск

```text
/setfaceit aghori-
/last
/stats
```

Бот проверит существование FACEIT-профиля и наличие CS2, сохранит его ID и канонический ник для вашего Telegram user ID **только в текущем чате**. Для настройки по-прежнему требуется доступность FACEIT API. Ошибочный ник или недоступность API не стирают прежнюю настройку.

`/last` и `/stats` после этого возвращают ваши картинки FACEIT Dark без текстовых отчётов. Если настройка отсутствует, вместо чужой статистики приходит графическая инструкция `/setfaceit ник` либо явный `/last ник` / `/stats ник`.

Кнопки «Последний матч» и «30 матчей» используют привязку того, кто нажал кнопку, даже если меню ранее открыл другой участник. Настройка общая для тем одного чата, но независимая в другом чате.

## Просмотр, замена и удаление

```text
/setfaceit
/setfaceit другой_ник
/unsetfaceit
```

Первая команда показывает последнюю сохранённую настройку и подсказку. Вторая заменяет только вашу привязку после успешной проверки нового профиля. Третья удаляет только вашу привязку в этом чате; дальнейшие запросы без ника снова требуют настройку.

Нельзя передать Telegram ID, @упоминание или второй аргумент, чтобы настроить другого человека. Команды изменения должны быть отправлены от собственного аккаунта, не пересланы и не от имени канала/анонимного администратора. Дублирующийся Telegram update не выполняет изменение повторно.

## Другой игрок и переименование

```text
/last другой_ник
/stats другой_ник
```

Явный ник всегда имеет приоритет и **не меняет** вашу личную настройку. Сохранённый FACEIT ID используется для запроса своего профиля: после переименования на FACEIT статистика относится к тому же аккаунту, а картинка показывает актуальный ник. `/setfaceit` без аргумента показывает сохранённый при настройке ник; чтобы обновить эту подпись, снова задайте актуальный ник.

Это удобная настройка, не проверка владения FACEIT: пользователь самостоятельно выбирает публичный профиль, OAuth/пароль FACEIT не запрашивается. Несколько участников могут выбрать один профиль.

## Хранение и ограничения

- Хранятся только chat ID, user ID, FACEIT player ID, ник и время настройки. Сырые сообщения для этого не сохраняются, привязки не выводятся в логи.
- Настройка переживает перезапуск и не удаляется TTL очисткой технических отчётов. `/unsetfaceit` удаляет её независимо от кеша публичной статистики.
- Базы локального резерва и облачной версии отдельные: автоматического переноса привязок между ними нет.
- При смене Telegram chat ID, в том числе basic group → supergroup, в новом ID нужно выполнить `/setfaceit` заново. Чужие настройки нового чата не перезаписываются.
- Существующие настройки TeamSpeak, опрос и постоянный кеш карточек не меняются. Совместная статистика не добавляется.
