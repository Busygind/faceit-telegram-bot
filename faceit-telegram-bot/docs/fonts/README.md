# Карточка FACEIT Dark: шрифт и переносимость

Карточка использует DejaVu Sans 2.37: латиницу, кириллицу, цифры и небольшую группу знаков пунктуации. Исходный открытый шрифт хранится в `assets/fonts/DejaVuSans.ttf`, лицензия — в `docs/fonts/DejaVu-LICENSE.txt`.

- [Проект DejaVu Fonts](https://dejavu-fonts.github.io/).
- [Исходный релиз 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).
- Системные шрифты Apple и YS не используются и не распространяются.

`tgcloud/lib/card-font.js` — заранее построенный сглаженный растр глифов, а не шрифтовый движок. Символы, которых нет в атласе, заменяются знаком `?`. Длинные имена безопасно сокращаются многоточием, полное имя остаётся в текстовом ответе бота. Аватар заменён монограммой; сетевых загрузок при рендеринге нет.

Для повторной сборки атласа нужен только инструмент разработки Python с Pillow; в Telegram Serverless он не нужен:

```sh
python3 scripts/build-card-font.py
```

Для создания демонстрационной карточки с явно синтетическими данными:

```sh
node scripts/render-demo.mjs
```

Рендерер не использует npm-пакеты во время выполнения, Canvas, DOM, файловую систему, `Buffer`, `TextEncoder` и встроенные компрессоры. Результат — PNG 864×1360 с несжатыми DEFLATE-блоками, около 3.53 MB: меньше лимита отправки фотографии Telegram 10 MB. Это сознательный обмен размера файла на предсказуемость переносимого рендеринга. Проверка фактического лимита времени и памяти Telegram Serverless остаётся частью приёмки в аккаунте владельца бота.

Показатели, их покрытие, статус неполной выборки и отметка устаревшего кэша берутся из того же отчёта, что текстовое сообщение; рендерер не пересчитывает статистику. Даты выводятся в МСК (UTC+3), без зависимости от `Intl` и системного часового пояса.
