# Работа с изменениями

1. Создайте отдельную ветку и откройте Pull Request в `main`.
2. Не добавляйте токены, реальные `.env`, `.secrets`, базы, выгрузки чата или generated `private-settings.js`.
3. Для живых экспериментов используйте отдельного тестового Telegram-бота и чат, не production-токен.
4. Запустите проверки из корневого README. Тесты не требуют настоящих ключей.
5. При изменении переносимого ядра синхронизируйте соответствующие файлы `faceit-telegram-bot/tgcloud/lib/` и `faceit-telegram-bot-sites/bot/core/`, пока ядро не объединено.
6. Опишите изменения и результаты проверок в PR. Merge не означает публикацию; рабочее развёртывание отдельно проверяет владелец.

Для вопросов и багов используйте Issues без сообщений чата и секретов. Open-source лицензия пока не выбрана.
